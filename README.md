# brennanbirn.github.io

Project portfolio site for CS280A: Intro to Computer Vision and Computational Photography, UC Berkeley, Fall 2026.

Once pushed to GitHub as `brennanbirn/brennanbirn.github.io` (public repo), GitHub Pages serves this
automatically at https://brennanbirn.github.io/.

## Structure

```
brennanbirn.github.io/
├─ index.html          main portfolio page
├─ stylesheet.css       shared site styling
└─ project0/
   ├─ index.html        Project 0 write-up
   └─ media/            images/gifs for Project 0
```

Each future project gets its own `projectN/index.html` + `projectN/media/` directory, linked from the
root `index.html`.
